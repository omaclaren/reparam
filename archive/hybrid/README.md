# Archived Hybrid Repressilator Artifacts

These files are preserved for historical reference from the deprecated hybrid/linear-path profiling exploration.

## Why archived?
- Hybrid mode (`--mode=hybrid`) has been removed from `run_repressilator_profile.jl`.
- The active workflow now uses slice/profile modes and canonical full-profile post-processing.

- `wald_profile_comparison.jl`
- `hybrid_profile_likelihood_summary.md`
- `repressilator_hybrid_*_results.jls`
- `repressilator_hybrid_*_results_replot.png`

These are not part of the active paper workflow, but retained for provenance.

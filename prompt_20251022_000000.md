## Technical Context

### Tolerance Parameters
- `rtolJ = sqrt(eps())` ≈ 1.5e-8: Relative tolerance for Jacobian rank determination
- `atolM = 1e-6`: Absolute tolerance for invariance test (relaxed for stiff ODEs)
- `atolM = 1e-10`: Default for smooth problems

### Invariance Methods
- `:hessian_based`: Nested AD, accurate for smooth problems
- `:finite_difference`: Required for stiff ODE systems (repressilator uses this)

### Transformation Convention
```julia
# Build transformation matrix (rows = parameter combinations)
A_full_T = hcat(N_perp, N)           # Stack as columns
A_full_T_scaled = scale_and_round(A_full_T)  # Integer coefficients
A_full = A_full_T_scaled'            # Transpose to get row combinations

# Apply transformation
ψ(θ) = exp.(A_full * log.(θ))
```
